How to play and teacher notes
  • Read the question and any code carefully. Code is written in OCR Exam Reference Language.
  • Press Show hint if you are stuck. The points for that question go down straight away.
  • For typed answers, capital letters do not matter. You do not need to type speech marks.
  • With teams, questions take turns between teams. The team whose turn it is answers.
  • Keyboard: 1 to 4 picks an option, Enter checks or moves on, H shows a hint.
  • Teachers: the whole game is one file and works offline. Your settings are remembered on this device. New questions can be added to the question bank inside the file (instructions are at the top of the file).
